1

Node.js පරිසරය Server පරිගණකයේ ස්ථාපනය කිරීම

පද්ධතියේ පසුබිම් සේවා (Backend Engine) ධාවනය කිරීම සඳහා නොමිලේ ලබාගත හැකි Node.js ස්ථාපනය කරගත යුතුය:

  1. වෙබ් බ්‍රවුසරයෙන් https://nodejs.org වෙත පිවිසෙන්න.
  2. එහි ඇති LTS (Long Term Support) අනුවාදයේ Installer ගොනුව බාගත (Download) කරගන්න.
  3. බාගත වූ Setup එක Run කර සාමාන්‍ය පරිදි Next කරමින් Install කරගන්න.
  4. ස්ථාපනය සාර්ථකදැයි පරීක්ෂා කිරීමට Command Prompt (cmd) විවෘත කර පහත විධානය ලබා දෙන්න:
node -v

Local SQLite දත්ත ගබඩාව (Offline Database) ක්‍රියාත්මක වීම
